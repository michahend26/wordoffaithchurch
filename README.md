# Word of Faith Church

A white-and-gold church website and installable web app foundation for Word of Faith Church — People With a Purpose.

## Stack
- Next.js App Router
- React
- TypeScript
- Responsive CSS
- Progressive Web App foundation

## Run locally
```bash
npm install
npm run dev
```

## Initial scope
- Responsive homepage and shared visual identity
- Ministry discovery
- Daycare and K–12 school entry points
- Planned Bible reader, sermons, worship audio, giving, and church connection features

## Before production
- Add the official high-resolution logo assets.
- Confirm church address, service times, contact information, and official program descriptions.
- Configure licensed Bible text/API access.
- Connect the church's chosen giving provider.
- Configure sermon and worship media sources.
- Add app icons and validate PWA behavior on iOS and Android.
- Review accessibility, privacy, and security.
